Slide 2 — Abstract
- **Overview:** Smart AgriCare automates field diagnosis by combining lightweight image-based ML with a knowledge-base fallback to deliver fast, actionable recommendations.
- **Objective:** Reduce diagnosis time and crop losses for small-to-medium farms using commodity smartphones.
- **Approach:** Client image upload → backend inference → fallback lookup → recommendation.

Slide 3 — Introduction
- **Problem:** Farmers lack timely access to expert diagnosis; crop issues can escalate rapidly.
- **Scope:** Smartphone-based image capture and web API for diagnosis of pests, diseases, and nutrient disorders.
- **Key features:** Fast inference, fallback knowledge base, simple UI, logging for analytics.

Slide 4 — Existing System
- **Manual expert visits:** Accurate but slow and costly.
- **Generic apps:** Low local accuracy for specific crops and conditions.
- **Paper/extension services:** Not real-time; limited personalization.
- **Heavy ML deployments:** Expensive; not suitable for small farms.

Slide 5 — Disadvantages of Existing Systems
- Slow response time
- High cost or low accessibility
- Low robustness across local varieties and field conditions
- Inefficient use of pesticides due to delayed/mistaken diagnosis

Slide 6 — Proposed System
- **Smart AgriCare:** Modular backend + lightweight inference + knowledge-base fallback.
- **Flow:** Image upload → analyze → if low confidence use KB lookup → return diagnosis & actionable steps.
- **Deployment:** Cloud or local server option; minimal resource requirements.

Slide 7 — Advantages
- Low-latency responses suitable for field use
- Robustness via KB fallback for low-confidence cases
- Extensible to sensors and data sources (soil, weather)
- Cost-effective and accessible to smallholders

Slide 8 — System Architecture (summary)
- Client (mobile/web), API service, Inference Engine, Knowledge Base, Database, Admin UI
- Data flow: Image → API → Inference → (KB fallback) → Recommendation → Log

Slide 9 — Use Case (one-liner)
- Actor: Farmer; Use case: Capture and upload image → receive diagnosis & treatment steps.

Slide 10 — Sequence (one-liner)
- Client uploads image; API calls Model; Model returns result; if low confidence API queries KB; API returns results.
